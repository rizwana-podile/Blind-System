# SIGHTGUIDE Caregiver Coordination Guide

The **Caregiver Module** in SIGHTGUIDE enables family members and authorized caregivers to support a blind or low-vision user with mutual consent, transparency, and dignity.

---

## 1. Principles of Respect & User Autonomy

1. **User In Control**: The blind or low-vision user has unilateral authority to initiate, inspect, or terminate location sharing and telemetry at any moment.
2. **No Stealth Surveillance**: SIGHTGUIDE will never function as covert tracking spyware. When sharing is active, the primary user is continuously notified via audio notifications and tactile indicators.
3. **Explicit Pairing**: A secure pairing ritual (such as scanning an ephemeral pairing QR code or exchanging an on-device generated passkey) must occur in person.

---

## 2. Caregiver Dashboard Views

When granted permission by the primary user, the Caregiver Dashboard provides:
- **Real-Time Location & Geofence Status**: Current location on map, timestamp of last update, and notification if user departs a designated safe zone.
- **Battery & Device Health**: Low-battery alerts (< 15%) so caregivers can remind the user to charge their device.
- **Assistance Activity Log**: Summary of recent navigation destinations or OCR sessions (without sensitive content).
- **Safety Status**: Live status of SOS alerts or fall detection triggers.
