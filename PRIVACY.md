# SIGHTGUIDE Privacy & Consent Model

## 1. Zero Covert Tracking Policy

SIGHTGUIDE adheres to strict, privacy-preserving standards:
1. **Never Track Without Consent**: Location is never sent to external servers or contacts without explicit user initiation or opt-in.
2. **Revocable Caregiver Sharing**: When the user opts to share location with a trusted contact, an ongoing persistent notification and a prominent dashboard indicator display the active sharing state. The user can revoke sharing at any time with a single tap or voice command ("Stop sharing location").
3. **No Phone-Number Location Traversal**: Location sharing requires device-to-device consent (such as QR pairing or mutual passkey exchange). No one can query a user's location simply from an entered phone number.

---

## 2. On-Device Data Processing

- **Camera Vision**: All camera frames processed by ML Kit for object detection and OCR occur strictly on-device. Frames are discarded immediately after analysis and are never written to disk or sent to any remote API.
- **Microphone / Voice**: Audio buffers are fed directly to the Android speech recognizer and intent parser. Raw audio recordings are not stored unless the user specifically records an audio voice note for themselves.

---

## 3. Data Sanitization & Logging

- Log entries generated by `:core:logging` automatically scrub Personally Identifiable Information (PII), such as:
  - Phone numbers (masked as `+1-XXX-XXX-1234`).
  - Precise GPS coordinates (latitude/longitude rounded to coarse region in debug logs, stripped entirely in production logs).
  - OCR text blocks.
